# 🔐 Password Generator & Strength Analyzer

A simple web application built with HTML, CSS and JavaScript to generate secure passwords and analyze password strength.

## ✨ Features

* 🔑 Generate random passwords
* 📏 Choose the password length
* 🔤 Enable or disable lowercase letters
* 🔠 Enable or disable uppercase letters
* 🔢 Enable or disable numbers
* 🔣 Enable or disable special characters
* 📋 Copy generated passwords to the clipboard
* 🛡️ Analyze the strength of a custom password
* 🔁 Detect repeated characters
* 🔢 Detect sequential characters
* 💡 Provide feedback and recommendations

## 🚀 Getting Started

### 1. Clone the repository

```bash
git clone https://github.com/YOUR-USERNAME/password-generator.git
```

### 2. Open the project

Open the project folder and launch `index.html` in your browser.

For the best development experience, a local development server such as Live Server can be used.

## 🔒 Privacy

Password analysis is performed locally in the browser.

The application does not send the passwords entered into the analyzer to a remote server.
